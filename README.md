# 📚 Práctica Académica Java: Algoritmia y Datos Deportivos

Este repositorio refleja una práctica técnica intensiva realizada durante mi formación en Programación Orientada a Objetos Avanzada (2º curso DAM). Usa el fútbol como pretexto para procesar y calcular datos matemáticos.

### 🔎 Retos técnicos resueltos:
* Uso puro de **Java SE** sin frameworks externos.
* Implementación sólida de Patrones de Diseño, Clases y Polimorfismo.
* Procesamiento intensivo de datos a través de *Java Collections Framework* (`Maps`, `Lists`).
* Cálculo algorítmico de puntuaciones y clasificación en un flujo automatizado de datos.
